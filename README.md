# Python Task Manager

A simple command-line task management application built in Python. This project was created to practise core Python concepts including functions, file handling, loops, conditional logic, and user input handling.

## Features

- Add tasks
- Edit existing tasks
- Delete tasks
- View saved tasks
- Store tasks persistently in a text file

## Technologies Used

- Python
- Text file storage

## Project Purpose

This was an early Python learning project focused on:

- Function-based program structure
- Reading and writing files
- List manipulation
- Terminal-based user interaction
- Basic CRUD operations

## How It Works

1. The user selects an option from the menu.
2. Tasks are saved in `tasks.txt`.
3. Existing tasks can be edited or deleted.
4. Changes persist between sessions.
