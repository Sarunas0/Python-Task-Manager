Python Task Manager

A simple command-line task management application built in Python. This project was created to practice core Python programming concepts including functions, file handling, loops, conditional logic, and user input handling.

Features
Add tasks
Edit existing tasks
Delete tasks
View all saved tasks
Persistent task storage using a text file
Technologies Used
Python
File handling with .txt storage
Project Purpose

This project was developed as an early Python learning exercise focused on understanding:

Function-based program structure
Reading and writing files
List manipulation
User interaction through the terminal
Basic CRUD operations (Create, Read, Update, Delete)
Example Workflow
User selects an option from the menu
Tasks are stored in tasks.txt
Users can update or remove tasks dynamically
Changes persist between sessions
Future Improvements

Potential improvements could include:

GUI version using Tkinter or PyQt
SQLite database integration
Task priorities and deadlines
Input validation improvements
Web-based version using Flask or Django
